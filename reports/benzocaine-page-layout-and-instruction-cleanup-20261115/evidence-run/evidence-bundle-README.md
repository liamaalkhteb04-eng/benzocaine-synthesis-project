# Benzocaine final-report evidence bundle

Curated current evidence for a later Solar Pro 4 final-report request. No Solar call or final report was generated in this update.

`results/report-evidence.json` is a derived copy of prediction evidence. Its `additional_analyses` block supersedes stale `not_implemented` statuses embedded in the historical source run. Original evidence, the old status JSON, frozen harness comparison input, and the two original trial drafts remain unchanged in their original project paths. The stale source status and frozen payload are excluded from the authoritative current bundle. The drafts are excluded because they themselves contain stale status language; the trial evaluation records their strengths, omissions, and contradictions.

Use current trial status, budget, redacted requests, raw responses, and comparison evaluation for harness facts. Use primary project evidence for chemistry. Do not treat either draft as authoritative.

Visualizer screenshots are actual BIOVIA Discovery Studio Visualizer screens. Alternative views were prepared with rigid coordinate transformations and then rendered in Visualizer; matrices and geometry-invariance checks are included. Structures are isolated. External reactant approach was not measured and no reaction pair was assembled.
