# OpenCode–Pi 초안 비교 평가 (trial 02)

## 실행 요약

두 하네스는 각각 새 실행 ID로 1회 성공 응답을 받았다. 두 응답은 사례 비교이며, 하네스 일반 성능의 우열을 입증하지 않는다.

| 항목 | OpenCode | Pi Coding Agent |
|---|---:|---:|
| 실행 ID / HTTP | `opencode-trial-02` / 200 | `pi-trial-02` / 200 |
| 모델 snapshot | `solar-pro4-260806` | `solar-pro4-260806` |
| 입력 / 출력 토큰 | 65,764 / 1,128 | 65,425 / 3,458 |
| 지연시간 | 14.796 s | 31.587 s |
| API 요금 추정 (VAT 전) | $0.0210828 | $0.0237771 |
| VAT 포함 추정 | $0.02319108 | $0.02615481 |
| 저장된 응답 길이 | 약 2,717자 | 약 8,881자 |

실제 응답, 사용량 메타데이터, 정규화된 요청 본문은 각 run 폴더에 저장했다. 성공 응답의 요금은 공개 토큰 단가로 계산한 추정치이며, API 응답에는 계정의 크레딧 차감 영수증이 포함되지 않는다.

## 입력과 생성 설정

- 두 실행은 같은 12개 자료 번들(SHA-256 `636BE4F7EE73A4BD08682629B95F906EC246A986E07C17348BB4EA93F72A973E`)과 같은 타깃·작업 요청을 사용했다. 모델, temperature 0, reasoning `none`, `max_tokens=10000`, `n=1`, 도구 비활성화는 가드가 동일하게 적용했다.
- 각 실제 요청에 12개 출처 블록과 보고서 작성 요청이 포함됐고, 처음 전달된 외부 POST 한 번씩으로 완료됐다. OpenCode의 명시적 `--title` 옵션이 제목 생성용 별도 호출을 막았다. Pi의 `supportsStore:false` 설정으로 `store`가 전송되지 않았다.
- 하네스가 실제 직렬화한 메시지는 바이트 단위로 같지 않았다. OpenCode는 시스템 메시지 1,348 B, 사용자 메시지 199,764 B를 보냈고, Pi는 각각 585 B, 199,832 B를 보냈다. 사용자 메시지의 일부 차이는 첨부 파일 래퍼에서 왔고 시스템 프롬프트 래퍼도 달랐다. 따라서 동일한 자료와 설정을 유지했지만, 하네스 자체의 system framing은 비교 변수로 남는다.
- 로컬 모의 서버 통합 검증도 완료했다. 검증 응답은 `LOCAL_MOCK_ONLY`로 분류했으며 실제 결과와 혼동하지 않는다. 각 하네스가 첫 POST에 보고서 작성 요청과 자료 12개를 넣는 것, Upstage 허용 필드만 전달하는 것, 스트리밍 차이를 가드가 처리하는 것을 확인했다.

## 확인된 불일치와 해석

1. **오래된 상태 파일:** 공통 번들 안의 `additional-analysis-status.json`에는 MOPAC·EPI Suite·Visualizer 및 하네스 비교가 `not_implemented`로 남아 있었다. 반면 함께 들어간 최신 해석 파일에는 MOPAC 25/25 수렴, 실제 EPI 응답, Visualizer 두 배좌 측정이 기록돼 있었다. OpenCode는 하네스 비교를 “도구 실행 미승인/미구현”이라고 썼고 Pi는 앞부분에서 추가 분석을 “준비/미실행”이라고 했다. 이는 입력 파일끼리 상태가 충돌한 영향이다. 현재 상태는 이 평가와 `trial-02-status.json`을 기준으로 읽어야 한다.
2. **Pi 내부 모순:** Pi 초안은 2절에서 MOPAC·EPI·Visualizer가 준비/미실행이라고 쓴 뒤 5절에서 실제 계산·조회·측정 결과를 자세히 기술한다. 같은 문서 안에서 정정되어야 한다.
3. **Visualizer 한계:** 실제 측정값은 ethyl 4-nitrobenzoate의 PM7 배좌 1·2에 대한 내부 N10–H21 거리와 C8–C9–N10 각도뿐이다. 반응물 접근 거리·공격각 측정은 없다. 따라서 초안의 접근성 표현은 분자 내부 기하의 유사성 관찰로 한정해야 한다.
4. **수치 분석 부족:** 두 초안 모두 EPI Suite에서 조회한 MP/BP 숫자와 MOPAC 에너지·기하의 대표 수치를 거의 제시하지 않았다. 실제 분석값을 포함할 후속 최종 보고서에서 보완이 필요하다.
5. **최종 보고서 준비도:** 둘 다 최종 보고서는 아니며 그림, 구조 이미지, 실제 URL을 연결한 참고문헌, 페이지 검증을 제공하지 않는다. 따라서 어느 초안도 제출용으로 확정할 수 없다.

## 비용 한도와 원장

- trial 02의 실제 토큰 사용 기준 추정은 합계 $0.0448599(VAT 전), $0.04934589(VAT 포함)다.
- 보수적 누적 상한은 사용자 보고 2026-11-02 크레딧 사용 $0.08 + 이전 trial의 요청 예약 상한 $0.264 + 이번 trial 예약 상한 $0.264 = **$0.608**다. 이는 사용자가 허용한 $1보다 낮다.

- 실행 후 Console을 다시 확인하지 못했으므로 이번 두 호출의 실제 계정 차감 및 현금 청구액은 독립 확인하지 않았다. 결제 설정 변경·충전은 하지 않았다.

이 결과는 각 하네스를 한 번씩 실행한 사례 평가다. 실제 보고서의 문체·정확성을 일반화하지 않으며, 최종 제출 보고서는 Solar Pro 4가 스킬과 최신 근거를 읽어 작성하고 추가 분석을 포함해 참고문헌까지 20쪽 이내여야 한다.
