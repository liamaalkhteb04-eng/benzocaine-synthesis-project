# 과거 자료 보관 — 필요한 기록은 삭제하지 않음

| 경로 | 역할 | GitHub 대상 |
|---|---|---|
| `baselines/baseline20.md` | 확정 전20쪽 원고의 해시 보호 사본. 재조판 계약이 읽음. 원문과 당시 report/ 위치 기준 링크를 그대로 보존 | 포함·필수 |
| `history/report-records/` | 과거 시안·변경 전후·삭제/인용/교정 이력 | 포함 |
| `history/evidence-files/S01__report.md` | 과거 보고서 초안. 현재 사실보다 우선하지 않으며 새 작성 정답으로 사용하지 않음 | 포함 |
| `history/skill/used-revision-system.txt` | 과거 실제 수정 호출의 system 이력 | 포함 |
| `history/figures/` | 이전 그래프/구조 조각·중간 시안 | 포함 |
| `duplicates/` | 옛 자료 대응표·기준 그림 원본·중복 교정 증명 | 포함 |
| `local-checks/` | 로컬 이동성 smoke·생성된 미호출 요청 등. 필요한 코드와 결과 요약은 code/·validation/에 있음 | 제외·로컬 보존 |

현재 사용하는 그림13개는 `report/assets/`에 있고 figure manifest도 그 위치를 가리킨다. 새 작성 시험 코드의 `authoring/section-pipeline/data/assets/`는 독립 실행용 자산 복사본이므로 현재 입력에 포함한다. 파일 수를 줄이기 위해 실행에 필요한 그림·기준 원고·근거를 삭제하지 않았다.

이 보관 폴더 전체를 Solar 새 작성 입력으로 제공하지 않는다. 해시 보호용 baseline은 원래 링크를 유지한 역사 문서이며, 현재 열 자료는 [최종 자료 대응표](../report/records/source-index.md)를 사용한다.
