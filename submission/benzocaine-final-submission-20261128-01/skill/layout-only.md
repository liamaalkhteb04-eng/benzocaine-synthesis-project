# 저장 원고 조판 규칙

이 절차는 기존 Solar 원고를 재조판하며 새 과학 문장·해석·캡션을 생성하지 않는다. report.md의 바이트와 그림13개의 해시를 유지한다. 본문·표·그림·출처 삭제와 문장 변경으로 쪽수를 맞추지 않는다. 맑은 고딕 본문11pt·표10pt·캡션10pt를 유지하며 문단 간격·표 여백·줄 간격·페이지 나눔부터 조정한다. Word의 문서 격자와 글꼴 기본 높이 때문에 실제 행간이 달라질 수 있으므로 실제 Word 재페이지와 PDF 내보내기로 확인한다. 그림을 포함하는 문단에는 고정 행 높이를 적용하지 않는다. 그림·캡션·제목을 연결하고 표 머리글을 반복한다. 저장된 DOCX를 Word가 실제 페이지 계산한 수와 해당 DOCX에서 내보낸 PDF 페이지 수를 대조한다. 쪽수만 맞고 내용이나 그림이 잘린 결과는 반려한다.
