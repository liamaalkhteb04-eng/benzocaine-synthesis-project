# 외부 원문 확보 범위

## 한국어 안내

수업 강의 PDF·문헌 스캔의 원본은 재배포 조건을 확인하지 않아 이 제출 폴더에 넣지 않았다. 이것은 원고 재조판의 누락 파일이 아니다. 보고서 그림13개와 확인된 수치·절차 요약·출처 ID·해시는 포함했다.

- OrgSyn: https://doi.org/10.15227/orgsyn.008.0066 ; PDF2쪽 도식·Procedure1. 원본 SHA256 a7406ae755631c3c47e39a51fb83b7bd83b2910d10aeffe99305ff1d83838a9d.
- 특허: https://patents.google.com/patent/US3037046A/en ; ExampleIV. 원본 PDF SHA256 af1376753ea61c3fbc448ed2b3555e7e145611563170fcca8e0d8a553321b913.
- 강의 원문: 수강자가 LMS에서 확보. 제공된 쪽수 메모는 근거에 포함됐지만 이 패키지가 원문을 배포하지 않는다.
- 체크포인트·대용량 USPTO 원본 데이터·stock·RDKit/MOPAC/Visualizer/Word 설치본은 포함하지 않는다. 기존 model-assets.lock.json 및 외부 출처로 식별한다. 새 화학 추론의 자동 재현 완료를 주장하지 않는다.
