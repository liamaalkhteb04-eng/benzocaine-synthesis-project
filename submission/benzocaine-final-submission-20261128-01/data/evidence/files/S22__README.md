- 입력 25개에서 `PM7 PRECISE GNORM=0.5 CHARGE=0 MS=0 PRTCHAR PRTINT THREADS=1` 확인. 중성·폐쇄껍질 RHF 상태는 출력과 함께 확인했으며 `MS=0` 문자열만으로 판정하지 않았다. 버전은 원시 출력 `MOPAC v23.2.5`, 상세 commit은 run-manifest 기록이다.
- 5종 × 시작 배좌 5개: 25/25에서 SCF 완료, 정상 종료, 최종 gradient < 0.5 확인. 실제 범위 0.29806–0.49866. 이는 **저장된 수렴 기준 충족**이지 검증된 물리적 정확도나 진동수 최소점의 증명이 아니다. [GNORM 공식 설명](https://openmopac.net/Manual/gnorm.html), [MS 공식 설명](https://openmopac.net/Manual/ms.html) (조회 2026-11-24).
- RDKit ETKDGv3/MMFF94s는 시작 구조 준비 단계다. MMFF94s 최저 시작 배좌와 최종 PM7 최저 배좌는 다른 선택이다. 최종 저장 구조는 같은 종의 다섯 수렴 결과 중 최저 생성열을 선택했다. 전역 최소점·볼츠만 분포는 검증하지 않았다.
- 기존 요약과 원시 출력의 생성열·gradient·쌍극자는 25/25 일치. 원시 ARC 최종 좌표로 기존 78개 결합 거리를 다시 대조하여 차이 0 Å. 원시 OUT 원자 전하 400행과 CSV도 400/400 일치. 이는 저장 자료의 추출 일관성 검사이지 새 MOPAC 계산이 아니다.
- 보고서의 대표 결합 거리(Å)는 위 CSV/ARC와 일치한다: nitro ester C=O 1.2050, C–O 1.3528, aryl C–N 1.4603, N–O 둘 다 1.2198; benzocaine C–N 1.3772/C=O 1.2080/C–O 1.3613; PABA C–N 1.3760/C=O 1.2071/C–O 1.3654; ethanol C–O 1.4142; acetic acid C=O 1.2021/C–O 1.3612. 표시 자릿수는 계산 정확도 보증이 아니다.

## 출처 무결성에서 발견한 차이

현재 체크아웃 파일은 LF 줄바꿈이므로 실행 당시 manifest의 SHA256과 **입력/OUT/ARC 각 25개 모두 바이트 해시가 다르다**. LF를 CRLF로 변환한 바이트의 해시는 **75/75 모두 manifest와 정확히 일치**했다. 따라서 확인된 차이는 줄바꿈이며 화학 내용 변경 증거는 없다. 원본은 변환하거나 수정하지 않았다. `raw_jobs_audit.csv`의 `manifest_hashes_match=False`는 이 바이트 비교 결과이며 수렴 실패가 아니다. 상세 결과는 `newline_hash_audit.json` 참조.

`analyses/preparation/structure-preparation.json`의 `preparation_only_not_calculated`, `mopac_invoked=false`는 **이전 준비 단계 기록**이다. 이후 실제 계산 여부는 25개 원시 출력과 `analyses/mopac/run-manifest.json`으로 판정한다. 과거 기록을 고치거나 삭제하지 않았다.

## 추가 계산 필요 여부

**이번 과제의 제한된 기술적 설명에는 추가 계산이 필수 아님.** 따라서 추가 계산을 제안하거나 실행하지 않고 여기서 마무리한다. 최소점 검증을 새 주장으로 추가하려는 경우에만 선택 5개 구조의 진동수/Hessian 검사가 최소 추가 범위다. 그것으로도 반응성·접근성·수율은 입증되지 않는다. 반응 경로나 수율을 주장하려면 실제 반응 조건/실험 등 별도 근거가 필요하며, 현재 범위에서는 미확인으로 남기는 것이 적절하다.
