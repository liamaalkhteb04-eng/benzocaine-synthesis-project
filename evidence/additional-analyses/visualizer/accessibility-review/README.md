# Visualizer accessibility supplement

- `accessibility-observations.md`: qualitative observations and interpretation limits.
- `single-conformer-input-manifest.json`: one-record SDF copies and source hashes.
- `orientation-views-manifest.json`: rigid transformations and pair-distance invariance checks.
- `observation-index.csv`: route, material, conformer, atom identifiers, actual Visualizer screenshot, and observation scope for every view.
- `visualizer-accessibility-session.json`: application/session details and reused prior GUI measurements.
- `screenshots/`: actual Discovery Studio Visualizer captures, including the single-record route-01 conformer-2 view. The no-change screenshot records the unsuccessful direct rotate-tool attempt and is not an observation.

No new distance or angle was measured. The four older route-01 measurements remain in the parent `analyses/visualizer/visualizer-measurements.csv`.
